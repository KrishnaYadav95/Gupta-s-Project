# MarketLens — Vercel Standalone

This version is configured as a single Vite/React deployment for Vercel.

## Deploy
1. Upload/import this project into your existing Vercel project.
2. Build command: `npm run build`
3. Output directory: `dist`
4. No backend URL or environment variable is required.

## Important
This standalone version cannot provide real-time stock prices without an external market-data provider.
The included demo data keeps the application functional without a separate backend.
